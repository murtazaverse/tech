01 / Context

The problem

Procurement analysts need answers spanning spend data, vendor information, and documents. An assistant must select valid tools and retrieve relevant evidence for different types of questions.

02 / Approach

How the pieces connect

KIRA combines LangChain and Pydantic AI with specialized agents for spend analysis, vendor insights, and document retrieval. Model and tool routing, relevance filtering, and guardrails support those workflows.

04 / My work

My engineering contributions

  • Contributed to KIRA's tool calling and automated spend analysis, resolving 50–60% of standard analyst queries.
  • Implemented JEV model and tool routing and RAG relevance filtering to select valid tool combinations and remove irrelevant document results.
  • Developed specialized agents supporting 4+ procurement workflows and evaluated tool calls, retrieval, and answer quality across 50+ test cases.

Professional work. This case study describes my contributions at a high level; internal code and implementation details are not shared.

05 / Engineering considerations

The decisions around the system

These are the tradeoffs this type of system needs to account for.

  • Specialized agents separate concerns but make tool selection and orchestration part of the reliability problem.
  • Relevant evidence and valid tool calls need their own checks; fluent answers alone are insufficient.

06 / Outcome & status

What came out of it

50–60% of standard analyst queries resolved through tool calling and automated spend analysis. Contributions supported 4+ procurement workflows, with evaluation across 50+ test cases.
