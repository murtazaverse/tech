GUI Based Real-time Facial Feature Detection

  • Tech Stack: MATLAB, Viola-Jones algorithm
  • Github URL: Project Link

The project utilizes the Viola-Jones algorithm to detect eyes, face, and upper body in real-time from a webcam video feed.

The project features a MATLAB GUI that allows users to easily interact with the system, providing real-time visualization of the detected facial features.

The project has applications in surveillance, human-computer interaction, biometrics, medical imaging, and facial expression analysis, offering potential uses in various fields.
