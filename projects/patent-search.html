01 / Context

The problem

Manual patent triage takes time and requires finding relevant evidence in technical documents. Useful search results also need to fit an analyst's reporting workflow.

02 / Approach

How the pieces connect

The system combines Pydantic AI, FastAPI, LangChain, MongoDB, and structured outputs. RAG components and semantic chunking retrieve relevant patent evidence and support structured Excel reports.

03 / System overview

From input to useful output

  1. Technical question
  2. Semantic retrieval
  3. Patent evidence

Conceptual overview based on the project description.

04 / My work

My engineering contributions

  • Built a patent-search system that reduced manual patent triage by 40%.
  • Designed RAG components and semantic chunking for evidence retrieval and structured Excel reporting.
  • Built ETL pipelines for chemical ontology and knowledge-graph data, and benchmarked models with precision, recall, F1, and ROC-AUC.

Professional work. This case study describes my contributions at a high level; internal code and implementation details are not shared.

05 / Engineering considerations

The decisions around the system

These are the tradeoffs this type of system needs to account for.

  • Chunking must preserve useful technical context while keeping retrieved evidence focused.
  • Structured outputs make results easier to use downstream; retrieval and model quality still require evaluation.

06 / Outcome & status

What came out of it

40% less manual patent triage, alongside evidence retrieval, structured reporting, chemical-data ETL, and model benchmarking.
